## 二、主循环 _scan_loop (scan_loop_runner.py)

### L37-76: 阶段分派
```
while _is_running:
    phase = MarketPhase.classify()
    WEEKEND → 60秒持仓检查
    is_in_trading → _scan_loop_trading()
    PREMARKET/AUCTION → _handle_premarket_phase() (60-120秒)
    AFTER_CLOSE → daily_settlement() (60秒)
    其他 → sleep(300)
```

### _scan_loop_trading (L106-155):
```
1. 看门狗: 风控线程死→重启
2. 行情降级恢复(5分钟一次)
3. 尾盘(14:30+): 只查持仓, 3秒/轮
4. elapsed >= current_interval? → scan_once()全量
5. else → 非全量轮: 30秒刷新行情+持仓检查+sleep(check_interval)
```

**时序推导(早盘120秒间隔)**:
1. T=0: elapsed=∞ → 全量扫描(10秒) → last_full_scan=T0
2. T=10: elapsed=10秒 < 120 → 非全量 → sleep(30秒) → continue
3. T=40: elapsed=40秒 < 120 → 非全量 → sleep(30秒) → continue
4. T=70: elapsed=70秒 < 120 → 非全量 → sleep(30秒) → continue
5. T=100: elapsed=100秒 < 120 → 非全量 → sleep(30秒) → continue
6. T=130: elapsed=130秒 ≥ 120 → **全量扫描** → last_full_scan=T130

**实际周期 = 全量耗时(10秒) + 4×30秒sleep = ~130秒**

9:30-10:00(30分钟) → 30/130 ≈ 14轮全量 + 56次行情刷新

## 三、风控线程 _risk_loop_sync (risk_loop_runner.py)

### L32-62: 每秒tick
```
while _risk_running:
    tick += 1
    _risk_tick_body(tick)
    time.sleep(1)
```

### _risk_tick_body (L65-87):
```
1. 阶段判断(非交易→sleep返回)
2. 加cache_lock深拷贝realtime_cache ← 可能30秒~5分钟前
3. 缓存>120秒→告警
4. 每1秒: _check_stop_loss_only() ← 核心止损
5. 每30秒: _check_positions_quick() (asyncio.run_coroutine_threadsafe)
6. 每60秒: check_pending_sells_timeout() (跌停挂起>30分钟→市价强卖)
```

### _check_stop_loss_only (scanner.py L780-804):
```
1. 非连续竞价→return
2. _retry_pending_sells() ← 跌停恢复重试
3. position_manager.check_stop_loss_only(realtime_data)
   → 固定止损: current_price <= avg_cost*(1-stop_loss_pct)
   → 追踪止损: activated and current_price <= stop_price
4. _execute_sell_list_from_risk() → broker.place_order(sell)
```
