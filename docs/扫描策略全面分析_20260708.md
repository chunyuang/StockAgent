## 七、分级追踪止损逻辑审查

### 7.1 参数体系

```
BASE = 5% (统一)
策略偏移量:
  first_limit_up:  +3/+6/+10/+13  → 8%/11%/15%/18%
  halfway_chase:   +1/+3/+6/+9    → 6%/8%/11%/14%
  dragon_head:     +2/+4/+7/+10   → 7%/9%/12%/15%
  limit_down_qiao: +0/+2/+5/+8    → 5%/7%/10%/13%
  limit_up_open:   +0/+3/+6/+9    → 5%/8%/11%/14%
  default:         +0/+2/+5/+8    → 5%/7%/10%/13%

高盈利紧缩: peak≥8% → 3% (仅halfway/dragon/ldq)
```

### 7.2 逻辑问题

1. **激活阈值与分级base不匹配**：
   - halfway_chase: 2%激活 → 但base=5%，激活后回撤容忍6%
   - 盈利2%时：止损线 = 最高价×(1-6%) ≈ 成本×1.02×0.94 = 成本×0.9588 → 低于成本
   - 兜底到固定止损(成本×0.97) → 实际止损线=成本×0.97
   - **结论：2%激活+6%回撤 = 等于没激活，止损线就是固定止损**

2. **高盈利紧缩过于激进**：
   - halfway_chase盈利8%→回撤容忍从11%骤降到3%
   - 这意味着盈利8%的股票，从最高点回撤3%就卖
   - 对于半路追涨，8%盈利后3%回撤很常见，会被大量洗出

3. **first_limit_up回撤容忍过宽**：
   - 盈利5%→回撤容忍11%，止损线=最高价×0.89
   - 首板票波动大，11%回撤可能从+5%回到-6%

## 九、追踪止损参数优化建议

### 当前问题总结

```
halfway_chase: 激活2% → base5% + offset1% = 6%回撤
  → 2%激活但6%回撤 > 2%盈利 → 止损线低于成本 → 兜底固定止损
  → 实际效果: 激活=没激活, 止损=固定3%

first_limit_up: 激活2% → base5% + offset3% = 8%回撤
  → 同上, 更严重: 8%回撤远超2%盈利
```

### 建议方案

**方案A：统一激活阈值=5%（推荐）**

将halfway_chase和first_limit_up的trailing_stop_pct从0.02改为0.05：
- 激活5% → 回撤容忍6%(halfway) / 8%(首板)
- 盈利5%时止损线 = 成本×1.05×0.94 = 成本×0.987 → 仍盈利-1.3%
- 兜底到固定止损(成本×0.97) → 止损线=成本×0.987(追踪止损生效!)

**方案B：分级base跟随激活阈值**

不推荐——会导致不同激活阈值的策略分级逻辑不同，增加复杂度

**方案C：激活阈值3%（折中）**

halfway_chase改为0.03，first_limit_up保持0.02：
- halfway: 激活3% → 回撤6% → 止损线=成本×1.03×0.94=成本×0.968 → 兜底固定止损
- 仍然不理想

**结论：方案A最优**，5%激活+6%回撤，止损线刚好在成本上方，真正起到追踪保护作用
