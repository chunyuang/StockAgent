## 二、主循环(_scan_loop)详细时序

### 2.1 一天的完整扫描时序

```
09:00-09:15  盘前: 仅检查持仓跳空(premarket_auction)  120秒/轮
09:15-09:30  竞价: 全市场竞价扫描(premarket_scan)     60秒/轮
             ├─ 行情获取(东财竞价数据)
             ├─ 策略筛选→9层管道→信号
             └─ 写入premarket_snapshots
09:30-10:00  早盘高峰: scan_once全量扫描              120秒/轮(配置)
10:00-11:00  早盘延续: scan_once                      180秒/轮
11:00-11:30  早盘尾段: scan_once                      300秒/轮
11:30-13:00  午休: 不扫描(行情缓存可能过期)
13:00-14:00  午盘初段: scan_once                      300秒/轮
14:00-14:30  午盘后段: scan_once                      180秒/轮
14:30-15:00  尾盘: 只做持仓检查,禁止新开仓             3秒/轮
15:00+       盘后: 结算+持久化                         60秒/轮
```

### 2.2 全量扫描轮之间的非全量轮

```python
# scan_loop_runner.py L166-195
if elapsed >= current_interval:
    await self.scan_once(trade_date)   # 全量扫描
    return True
else:
    # 非全量轮: 30秒刷新行情+持仓检查
    check_interval = self._get_smart_check_interval(positions)
    if quote_age > 30:
        realtime_data = await self._fetch_realtime_batch(force=False)
        await self._check_positions(realtime_data, trade_date)
    await asyncio.sleep(check_interval)  # 10~30秒
    return False
```

**非全量轮作用**：两次全量扫描之间，每30秒刷新行情缓存(东财TTL<5s返回缓存)，避免风控线程用5分钟前的价格做止损。

## 五、异动检测详细

### 5.1 三种异动类型

| 类型 | strategy | 检测条件 | 数据来源 |
|------|----------|----------|----------|
| **急速拉升** | anomaly_surge | 5分钟涨幅>3% 且 非涨停 | 当前价vs上一轮缓存价 |
| **强势涨停** | anomaly_strong | 涨停 且 封单>1亿 且 无炸板(open_times=0) | 东财fd_amount+open_times |
| **涨停炸板** | anomaly_broken | 炸板(is_broken_board) 且 非跌停 且 涨幅>5% 且 开板≤2次 | 东财is_broken_board+open_times |

### 5.2 异动信号的处理路径

```
detect_anomalies(realtime_data)
  → 遍历5400只(不额外API, 用已有realtime_data)
  → 产生anomaly_surge/anomaly_strong/anomaly_broken信号
  → _apply_filter_pipeline(anomaly_signals, source="anomaly")
    → L1-L9全管道(与主扫信号相同)
  → 合并到new_signals
```

### 5.3 anomaly信号的真实转化(修正)

anomaly不是独立策略，是异动标签。同一只票可能同时产生anomaly信号和halfway_chase信号，买入时strategy写halfway_chase。

**数据验证**：
- anomaly_surge 918个new → 其中39只代码与halfway_chase买入重叠
- 所以anomaly"0成交"是统计口径问题，实际~30只通过halfway_chase买入

## 六、9层管道逐层详解

| 层 | 名称 | 代码位置 | 逻辑 | 拦截效果 |
|----|------|----------|------|----------|
| L1 | 强制空仓 | live_filter_pipeline L1 | 涨停≤10 或 跌停≥80 或 大盘跌≥3% → 清仓 | 极少触发 |
| L2 | 特殊时期 | L2 | 节假日/会议/月末 → 降仓系数 | 偶尔 |
| L3 | 情绪周期 | L3 | 情绪<40冰点→25%仓位; 40-55→50%; 55-70→70%; ≥70→100% | **持续生效** |
| L4 | 盘前预选 | L4 | 排除ST/退市/次新(<60天)/低流动(<500万) | ~10% |
| L5 | 竞价过滤 | L5 | 排除极端竞价(高开>7%/低开<-5%) | ~10-20% |
| L6 | 策略量能 | L6 | 复用回测策略筛选条件(fail-closed) | **主拦截层** |
| L7 | 综合排序 | L7 | 优先级+去重+截断10只 | 少量 |
| L8 | 仓位控制 | L8 | 情绪×特殊×单票35%×总仓50-70% | 按仓位 |
| L9 | 买入执行 | L9 | T+1检查/跳空止损/成交概率模拟 | 首板受限于成交概率 |

### L6策略量能的fail-closed机制

```python
# strategy_scorer._apply_filter_conditions
for cond in conditions:
    col = cond["name"]  # e.g. "pullback_pct"
    if col not in merged_df.columns:
        mask &= False  # 字段缺失→条件不满足→该票被过滤
```

**dragon_head 0信号根因**：
- 需要`pullback_days >= 1`和`pullback_pct <= -0.05`
- merge_factors中这两个字段补0(无法实时计算)
- 0 >= 1 → False → mask=False → 0候选

## 七、各策略筛选条件详解

### 7.1 halfway_chase(半路追涨) — 唯一有效策略

```
条件9条:
  pct_chg >= 3.0          # 涨幅≥3%
  pct_chg <= 9.5          # 涨幅≤9.5%(非涨停)
  volume_ratio >= 1.5     # 量比≥1.5
  turnover_rate >= 3.0    # 换手率≥3%
  turnover_rate <= 50.0   # 换手率≤50%
  circ_mv >= 100000       # 流通市值≥10亿(万元)
  circ_mv <= 5000000      # 流通市值≤500亿
  opening_pct_chg >= -2.0 # 开盘涨幅≥-2%
  intraday_max_rise_pct >= 3.0  # 盘中最高涨幅≥3%
```

漏斗: 5400只 → ~60候选 → 9层管道 → 0~5买入

### 7.2 first_limit_up(首板打板)

```
条件8条:
  is_limit_up == 1        # 当前涨停
  first_limit_up == 1     # 首板(昨日未涨停)
  volume_ratio >= 1.0     # 量比≥1
  turnover_rate >= 3.0    # 换手率≥3%
  turnover_rate <= 50.0
  circ_mv >= 100000       # 流通市值≥10亿
  circ_mv <= 5000000
  limit_up_count <= 1     # 炸板次数≤1
```

漏斗: 5400只 → ~10候选 → 9层管道 → 成交概率6.4%

### 7.3 dragon_head(龙头低吸) — 0信号

```
条件9条:
  limit_up_count >= 2     # 连板≥2(龙头)
  pullback_days >= 1      # 回调天数≥1 ← 补0! → mask=False
  pullback_pct >= -0.22   # 回调幅度≥-22%
  pullback_pct <= -0.05   # 回调幅度≤-5% ← 补0! → mask=False
  turnover_rate >= 2.0
  turnover_rate <= 30.0
  circ_mv >= 200000       # 流通市值≥20亿
  circ_mv <= 10000000
  pct_chg >= -5.0         # 当日跌幅≤5%
```

**根因**: pullback_days/pullback_pct补0 → 条件不满足 → 0候选

### 7.4 limit_down_qiao(跌停翘板) — 141信号0成交

```
条件9条:
  limit_down_yesterday == 1  # 昨日跌停
  open_above_limit_down == 1 # 开盘贴近跌停价
  pct_chg >= 1.0            # 当日反弹≥1%
  turnover_rate >= 1.0
  circ_mv >= 100000
  circ_mv <= 10000000
  volume_ratio >= 0.5
  limit_down_open_amount >= 100000  # 跌停开板成交额≥10万 ← 补0!
  sentiment_period_in in [...]      # 情绪阶段限制
```

**问题**: limit_down_open_amount补0 → 条件不满足 → 但141信号说明部分票通过了其他条件
