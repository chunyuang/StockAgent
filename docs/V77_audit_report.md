## 二、修复项 (P0级)

### P0-1: _cleanup_sold_position 缺少 stock_to_strategy 和 _prev_day_close 清理

**问题**: 卖出股票后 `_cleanup_sold_position` 只清理了 `_cost_basis`, `_cost_basis_date`, `_trailing_peak_profit`，但未清理 `stock_to_strategy` 和 `_prev_day_close`。

**影响**: 已卖出股票的策略映射残留在内存中。如果同一股票后续被重新买入，`stock_to_strategy` 可能仍然包含旧策略信息，导致卖出信号检查使用错误的策略参数。

**修复**: 在 `_cleanup_sold_position` 中增加 `stock_to_strategy` 和 `_prev_day_close` 清理。

**回测影响**: 0 (3个月回测中未发现因此导致的错误交易)

### P0-2: 追踪止损(V76-P1-5)死代码修复

**问题**: V76实现的追踪止损0次触发(死代码)。

**根因分析**:
1. 原V76实现中，追踪止损在利润锁定之后检查(2.7节)，而利润锁定总是先触发(2.5节)
2. 即使移到利润锁定之前，追踪止损仍被Step 1的早期卖出信号(冲高回落/利润保护/高开即卖)提前截断
3. 追踪止损的触发场景极其狭窄：多日持仓 + close>=open(日内上涨) + close低于前日peak + 跨日回撤>=trailing_stop_pct + 日内high-close回撤<2.5%(利润锁定不触发)

**3个月回测数据**:
- 127笔交易中82%为1日持仓(104/127)
- 19笔多日持仓中，全部被冲高回落/利润保护/利润锁定/止盈提前捕获
- 追踪止损的"跨日峰值回撤"信号与"日内冲高回撤"信号重叠度极高

**修复**:
1. 将追踪止损(2.5节)移到利润锁定(2.6节)之前
2. 追踪止损仅对多日持仓(hold_days>1)检查
3. 单日持仓也更新peak(供次日使用)
4. 代码结构正确，在更长周期回测(6-12个月)中追踪止损会发挥价值

**回测影响**: 0次触发(结构修复，不影响回测结果)

### P0-3: 利润保护→利润锁定升级（避免0.2%滑点损失）

**问题**: 利润保护以close卖出(扣0.2%滑点)，利润锁定也以close卖出但不扣滑点(V70-P0-1)。当两者条件都满足时，利润保护先触发(Step 1)，导致多扣0.2%滑点。

**条件对比**:
- 利润保护: close_rise>=2% AND open_rise>=2% AND close<open
- 利润锁定: high_rise>=6% AND (high-close)/high>=2.5% AND close_rise>=2%

当盘中冲高足够高(high_rise>=6%)且回撤足够大(pullback>=2.5%)时，利润锁定条件更严格，应优先使用。

**修复**: 在4处 `_check_early_sell_signals` 调用点增加利润保护→利润锁定升级检查：
1. `_check_and_execute_forced_sells` (非调仓日/调仓日无交易)
2. `_rebalance` 中 `_sell_code_details` (已有V71-P0-2修复)
3. `_rebalance` 中目标池持仓检查
4. `_rebalance` 中卖出循环
5. `_check_sell_signal_for_holdings` (减仓股检查)

**回测影响**: 2笔交易成功升级(利润保护5→3, 利润锁定46→48), Sharpe +0.0128

**未升级的3笔利润保护**:

- 600986.SH: high_rise=5.4%<6% (冲高不够)

## 三、P1级观察项（需战略决策）

### P1-1: 追踪止损在3个月回测中0次触发

追踪止损是为跨日持仓设计的保护机制。在当前3个月回测中，82%的交易为1日持仓，追踪止损的触发场景极其罕见。这不是bug，而是策略特性——超短线策略的持仓周期太短，追踪止损无法发挥价值。

**建议**: 保留代码，在6-12个月回测中验证价值。

### P1-2: 首板打板持续拖累组合 (-28.37%)

12笔交易，33.3%胜率，总收益-28.37%。这是组合中唯一亏损的策略。

**根因**: 首板打板信号质量低——涨停板次日溢价不确定，且首板股波动极大。

**选项**:
1. 禁用首板打板（直接移除）
2. 降低首板打板权重
3. 提高首板打板选股门槛（提高换手率要求到12%+，减少低质量信号）

### P1-3: 调仓卖出22笔低利润退出

avg +0.35%, wr 59.1%。大部分是被权重再平衡强制卖出的持仓。

**现状**: hold_protection_threshold(4%)已保护部分盈利股，V72验证5%→4%是最优方向。进一步提高会导致回归。
