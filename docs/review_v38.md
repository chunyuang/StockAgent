## V38核心发现：多策略调仓竞争

### 实验方法
单跑半路追涨策略，hold_protection 5% vs 6%：

```
hold_protection=0.05: 12.52%, 胜率54.84%, 31笔
hold_protection=0.06: 12.52%, 胜率54.84%, 31笔  ← 完全一致！
```

### 结论
- 单策略时5%=6%结果完全相同——因为不存在跨策略调仓竞争
- 多策略同时运行时，5-6%盈利+阳线的股票在6%阈值下不被保护，被调仓卖出
- 半路追涨最受伤：胜率从68.2%(V35)→62.5%(V37)→65.2%(V38)
- 龙头低吸也受益：33笔93.9%胜率（V37: 32笔93.8%）
