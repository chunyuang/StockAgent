## 代码审查发现的问题

### P0级 (影响回测正确性)

1. **P0-1: _prev_day_close更新逻辑确认无bug**
   - 分析后确认: pre_close已从MongoDB直接读取(已验证正确), _prev_day_close仅作fallback
   - 同一天多次调用_get_prices不会造成问题(同一天close值相同)

2. **P0-2: 跌停翘板rise_after_limit_down因子有效率仅2%**
   - 该因子在昨日跌停+开盘不继续跌停+收涨的592只中仅7只≥3%
   - 当前代码target=0自动跳过,不影响结果
   - 建议后续考虑移除或替换该因子

3. **P0-3: 非调仓日cost_basis清理确认正确**
   - Python dict是引用类型,del holdings[code]确实修改原始dict

### P1级 (影响回测效率或结果质量)

1. **P1-1: 止损止盈检查3处重复代码**
   - _process_rebalance_day、_process_non_rebalance_day、_rebalance三处
   - V14已提取_check_early_sell_signals统一冲高回落检查
   - 止损止盈主体逻辑仍重复,但修改风险高,暂不重构

2. **P1-2: _compute_weights中score_map使用pct_chg(未来函数)**
   - 影响: 多策略同权时排序偏向当天涨得多的股票
   - 但max_stocks=3且席位制,实际影响有限

3. **P1-3: 强制空仓阈值参数传递路径需要正确**
   - force_empty_config需在params.params中,不能在顶层
   - 已在参数扫描中验证正确路径
