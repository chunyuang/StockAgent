# V74 回测模块审查报告

## 一、P0级修复（已完成并提交）

### P0-1: FactorQualityChecker错误中止回测
- **问题**: `opening_pct_chg`被标记为核心因子(CORE_FACTORS)，缺失时导致整日回测中止
- **影响**: 2年回测中大量交易日被跳过，实际只有约1/8的交易日参与交易
- **修复**: 新增`COMPUTABLE_FACTORS`集合，`opening_pct_chg/pullback_pct/pullback_days`可从已有字段动态计算，不应中止回测
- **文件**: `factor_quality_checker.py`

### P0-2: 因子引擎缺失因子未动态补算
- **问题**: 回测模式直接从MongoDB读取预计算因子，`opening_pct_chg`等字段缺失时factor_df中无该列
- **影响**: 与P0-1联动，导致FactorQualityChecker报告因子缺失
- **修复**: 在factor_engine.py回测模式中添加动态补算逻辑：
  - `opening_pct_chg`: 从`open/pre_close`计算（与MongoDB预计算公式一致）
  - `pullback_pct/pullback_days`: 缺失时设0（龙头低吸筛选自然跳过）
- **文件**: `factor_engine.py`

## 五、重要发现：V68基线有缺陷

**之前的V68基线(315%/117笔)是在P0 bug存在的情况下跑出的**：
- 因子缺失导致大量交易日被跳过
- 只有后期(2025年1月后)opening_pct_chg完整的日期才参与交易
- 实际只有约1/8的交易日参与

**V74修复后(434%/204笔)才是真正的完整基线**：
- 所有交易日都参与交易
- 3个月就有204笔交易(V68的2年才117笔)
- 收益更高但更真实地反映策略表现
