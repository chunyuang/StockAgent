## 1️⃣ 引擎核心逻辑审查

### 1.1 调仓日处理 (`_process_rebalance_day`)

**文件**: `portfolio_backtest.py` L1008-1699

**核心流程**:
```
1. 强制空仓检查 → 触发则直接清仓跳过选股
2. 获取股票池 → ST/新股/流动性过滤
3. 因子计算 → 27个超短因子
4. 情绪周期映射 → 市场级情绪评分
5. 多策略筛选 → 5个策略独立筛选
6. 竞价过滤 → 真实竞价数据或日线近似
7. 板块集中度过滤 → 每行业最多N只
8. 调仓执行 → 买入/卖出/减仓
```

**✅ 正确性验证**:
- 强制空仓时跳过选股计算 ✅ (修复#43)
- T+1约束：当日买入不可卖出 ✅ (Phase1修复)
- 情绪周期仓位系数正确应用 ✅
- 板块集中度过滤已实现 ✅ (P1-2修复)

**⚠️ 潜在问题**:
- **P3-1**: 竞价过滤在无真实数据时用 `opening_pct_chg` 近似，但该因子在日线数据中可能不准确（开盘价/前收盘价计算）
- **P3-2**: 板块集中度用 `pct_chg` 排序，但当日涨幅不代表股票质量（可能是追高）

### 1.2 非调仓日处理 (`_process_non_rebalance_day`)

**文件**: `portfolio_backtest.py` L1699-1899

**核心流程**:
```
1. 止损止盈检查 → 盘中触发价格
2. 跳空止损处理 → open<止损价用open卖出
3. 超时强卖检查 → 日历天数>max_hold_days*1.5
4. 次日高开即卖 → 跌停翘板/首板打板策略
```

**✅ 正确性验证**:
- T+1约束：当日买入不可止损/止盈 ✅
- 跳空止损：open<止损价用open卖出 ✅ (Phase1修复)
- 止损卖出价：止损价/跳空open，不再一律用close ✅
- 超时强卖：日历天数>max_hold_days*1.5 ✅

**⚠️ 潜在问题**:
- **P3-3**: 超时强卖用日历天数而非交易日天数，周末/节假日会导致误差
- **P3-4**: 次日高开即卖阈值硬编码为3%，应从策略参数读取（已修复P1-6）

### 1.3 调仓执行 (`_rebalance`)

**文件**: `portfolio_backtest.py` L3207-3718

**核心流程**:
```
1. 计算总资产 → open价估值持仓
2. 情绪仓位系数 → sentiment_multiplier
3. 特殊时期系数 → special_multiplier
4. 计算目标持仓 → 策略对应买入价
5. 首板打板成交概率 → 确定性hash模拟
6. 卖出逻辑 → T+1检查/止损止盈/超时强卖
7. 买入逻辑 → 策略对应买入价/滑点扣除
8. 减仓逻辑 → 超过目标部分卖出
```

**✅ 正确性验证**:
- T+1约束：当日买入不在sell_codes中 ✅
- 止损止盈检查：减仓前检查，触发则全卖 ✅
- 首板打板成交概率：确定性hash保证可复现 ✅ (P1-5修复)
- 买入价计算：多策略选同股取最低价 ✅ (P1-1修复)
- 停牌股处理：close=0时用最后有效价 ✅ (P0-1修复)

**⚠️ 潜在问题**:
- **P3-5**: 减仓逻辑用close价卖出，不考虑止损止盈（设计如此，减仓是调仓行为）
- **P3-6**: 停牌超时强卖阈值硬编码为15天，应可配置

## 5️⃣ 选股逻辑审查

### 5.1 策略筛选条件

**✅ 条件正确性**:
- 半路追涨：盘中涨幅+量比+开盘涨幅+收盘确认 ✅
- 首板打板：首次涨停+昨日未涨停+竞价涨幅+量比+换手率+市值 ✅
- 涨停开板：昨日涨停+今日未封住+量比+换手率 ✅
- 龙头低吸：市值+涨停数+回调幅度+回调天数+量比 ✅
- 跌停翘板：昨日跌停+开盘高于跌停+市值+换手率 ✅

**⚠️ 潜在问题**:
- **P3-21**: 龙头低吸用市值识别龙头，不够准确（应用涨停数/连板数）
- **P3-22**: 部分因子数据质量差（如market_leader全0，limit_up_open_amount大部分0）

### 5.2 买入价计算

**✅ 逻辑正确性**:
- 半路追涨：open*(1+min_rise*0.6) 模拟盘中触发价 ✅
- 首板打板：涨停价 ✅
- 龙头低吸：low+(high-low)*0.25 偏低位 ✅
- 跌停翘板：low*1.005 跌停价附近 ✅
- 多策略选同股取最低价 ✅ (P1-1修复)

**⚠️ 潜在问题**:
- **P3-23**: 买入价是近似模拟，与实盘成交价可能有差异
- **P3-24**: 半路追涨signal_fraction=0.6是经验值，未优化

## 6️⃣ 结果计算审查

### 6.1 净值计算

**✅ 逻辑正确性**:
- 每日净值 = 现金 + 持仓市值 ✅
- 持仓市值用close价计算 ✅
- 停牌股用最后有效价 ✅

**⚠️ 潜在问题**:
- **P3-25**: 净值计算用close价，与买入价（open/策略特定价）不一致

### 6.2 绩效指标

**✅ 指标正确性**:
- 总收益率 = (final_value - initial_cash) / initial_cash ✅
- 年化收益率 = (1 + total_return)^(252/trading_days) - 1 ✅
- 最大回撤 = max((peak - current) / peak) ✅
- 夏普比率 = (avg_return - rf) / std_return * sqrt(252) ✅
- 索提诺比率 = (avg_return - rf) / downside_std * sqrt(252) ✅
- 盈亏比 = total_profit / total_loss ✅

**⚠️ 潜在问题**:
- **P3-26**: 无风险利率硬编码为3%，应可配置
- **P3-27**: 年化收益率在少于30天时不可靠（已标注）

### 6.3 交易记录合并

**✅ 逻辑正确性**:
- FIFO匹配买入卖出 ✅ (P0-3修复)
- 完整交易记录包含买入价/卖出价/盈亏 ✅
- 未平仓持仓单独处理 ✅

**⚠️ 潜在问题**:

## 🔟 总结与建议

### 10.1 核心优势

1. **架构清晰**: 前后端分离，模块化设计
2. **参数统一**: 单一来源策略默认值
3. **逻辑正确**: T+1约束、跳空止损、成交概率模拟等核心逻辑正确
4. **日志完善**: 结构化日志支持调试和审计
5. **性能优化**: 批量查询、异步并发、缓存机制

### 10.2 主要风险

| 风险等级 | 问题编号 | 问题描述 | 影响 |
|---------|---------|---------|------|
| P3-9 | 因子缺失时仅告警 | 回测结果可能异常 | 中 |
| P3-22 | 部分因子数据质量差 | 选股结果不准确 | 中 |
| P3-25 | 净值计算用close价 | 与买入价不一致 | 低 |
| P3-29 | portfolio_backtest.py过长 | 可维护性差 | 低 |
| P3-42 | 无单元测试 | 回归风险高 | 中 |

### 10.3 优先建议

**高优先级**:
1. 添加因子数据质量检查，缺失时阻止回测或使用默认值
2. 添加单元测试，覆盖核心逻辑（止损止盈、T+1、成交概率）
3. 拆分portfolio_backtest.py，提升可维护性

**中优先级**:
4. 优化买入价计算，提升与实盘一致性
5. 添加数据校验，防止异常输入
6. 添加并发限制，防止资源耗尽

**低优先级**:
7. 优化情绪周期评分公式
8. 添加更多风控策略（移动止损、保本止损）
9. 完善文档和测试
