## 2. 核心差距根因分析

### 🔴 根因1: 选股完全不同 (重叠仅2只/49只)

实盘选了49只股票，回测选了15只，**重叠只有2只**（002025航天电器、002167东方锆业）。

| 差异点 | 实盘 | 回测 |
|--------|------|------|
| 信号源 | 盘中实时扫描(东方财富push2) | 历史日线数据回放 |
| 买入时机 | 信号产生后立即下单(盘中) | 次日开盘价买入 |
| 量比数据 | 实时量比(盘中动态) | 日线量比(全天均值) |
| 换手率 | 实时换手 | 日线换手 |
| 竞价数据 | 9:15-9:25竞价快照 | 无竞价数据 |

### 🔴 根因2: 跳空止损频发 (实盘12笔 vs 回测1笔)

**实盘20笔亏损中，12笔是跳空止损**，平均亏损-5.7%，远超3%止损线。

典型：红板科技-16.5%、龙磁科技-11.6%、金博股份-10.7%

回测只有1笔跳空止损，因为回测用次日开盘价买入，天然避开了盘中追高后次日跳空的风险。

### 🔴 根因3: 实盘交易频率过高 (39笔 vs 15笔)

实盘7天做了39笔交易（日均5.6笔），回测只做15笔（日均2.1笔）。

- 实盘scanner每30秒扫描一次，盘中信号密集
- 资金刚收回就立即再买入，仓位始终接近满仓
- 回测每天只选一次，且有仓位上限控制

### 🟡 根因4: 卖出策略差异

| 卖出原因 | 实盘 | 回测 |
|----------|------|------|
| 止损 | 3笔 | 1笔 |
| 跳空止损 | 12笔 | 1笔 |
| 追踪止损 | 6笔 | 0笔 |
| 冲高回落 | 4笔 | 0笔 |
| 止盈 | 1笔 | 5笔 |

## 5. 改进建议

### 🎯 P0: 降低跳空止损率 (影响最大)

跳空止损是最大亏损来源（12笔，占亏损60%）。根因是**尾盘追高买入**后次日低开。

1. **禁止14:30后买入** — 尾盘追高风险最高
2. **买入价不超过MA5的102%** — 避免追太高
3. **跳空止损改为观察1小时** — 开盘跳空可能是洗盘

### 🎯 P1: 控制交易频率

日均5.6笔太多，频繁换手增加摩擦成本。

1. **每日最多买入5笔**
2. **持仓≥8只时不再买入**
3. **买入间隔≥5分钟**

### 🎯 P2: 选股质量提升

实盘和回测选股重叠仅2只，说明盘中实时选股和回测历史选股逻辑差异大。

1. **增加MA5/MA10趋势过滤** — 只买趋势向上的票
2. **增加板块强度过滤** — 优先选热门板块
3. **回测也用盘中信号回放** — 缩小实盘-回测gap
