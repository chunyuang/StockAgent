# MongoDB 字段单位规范 (必读)

> **核心原则**: 不同数据源写入同一集合时，必须统一为同一单位标准。
> **写入前校验**: 任何脚本写入前必须检查字段值是否在合理范围内。

---

## stock_daily_ak_full 集合

| 字段 | 单位 | 合理范围 | 示例 | 备注 |
|------|------|---------|------|------|
| close/open/high/low/pre_close | 元 | 0.01-99999 | 25.38 | 真实价(不复权) |
| pct_chg | 百分数 | -30~+30 | 5.32 (表示5.32%) | 不是0.0532 |
| vol | 手 | 1-1e8 | 891848 | **手，不是股！** |
| amount | 百元 | 1-1e10 | 89184800 | **百元，不是元！** |
| turnover_rate | 百分数 | 0.01-100 | 5.31 (表示5.31%) | **不是0.0531！不是531！** |
| volume_ratio | 倍数 | 0-50 | 1.52 | 无量纲 |
| circ_mv | 万元 | 1-1e8 | 148800 | **万元，不是元！不是亿！** |
| is_limit_up | 0/1 | 0-1 | 1 | 布尔 |
| first_limit_up | 0/1 | 0-1 | 1 | 布尔 |
| limit_up_count | 整数 | 0-5 | 2 | 近5日涨停次数 |
| amplitude | 百分数 | 0-30 | 8.52 | 振幅% |

### ⚠️ 易错点

1. **turnover_rate**: 东方财富返回已是百分数(5.31)，直接存。搜狐返回"0.25%"需×100。Tushare返回小数(0.0531)需×100。**写入前必须检查>50则报错**。
2. **vol**: 东方财富返回手，直接存。AKShare返回股需÷100。**不是股！**
3. **amount**: 东方财富返回元需÷100。AKShare返回元需÷100。搜狐返回万元需×100。**百元！**
4. **circ_mv**: 东方财富返回元需÷10000→万元。Tushare返回千元需×10→万元。

## 数据源 → MongoDB 单位转换表

| 数据源 | turnover_rate源格式 | 转换 | vol源格式 | 转换 | amount源格式 | 转换 |
|--------|-------------------|------|----------|------|-------------|------|
| 东方财富(f8) | 百分数(5.31) | **直接存** | 手 | **直接存** | 元 | **÷100→百元** |
| 搜狐(turn) | "0.25%" | **×100→25.0** | 手 | **直接存** | 万元 | **×100→百元** |
| Tushare | 小数(0.0531) | **×100→5.31** | 手 | **直接存** | 千元 | **×10→百元** |
| AKShare | 百分数(5.31) | **直接存** | 股 | **÷100→手** | 元 | **÷100→百元** |

## 写入校验规则 (所有脚本必须遵守)

```python
# 写入前校验
def validate_before_write(doc):
    tr = doc.get('turnover_rate', 0)
    if tr > 100:  # 换手率>100%几乎不可能(除新股首日)
        raise ValueError(f"turnover_rate={tr}% 异常! 可能被×100了")
    
    vol = doc.get('vol', 0)
    if vol > 0 and vol < 100:  # vol=手, <100手不太可能(除极小盘)
        # 可能是股而非手
        pass  # 警告但不报错
    
    circ_mv = doc.get('circ_mv', 0)
    if circ_mv > 0 and circ_mv < 1:  # circ_mv=万元, <1万不太可能
        raise ValueError(f"circ_mv={circ_mv}万元 异常! 可能是亿元")
```
